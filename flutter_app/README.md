# خوارزمي | تطبيق العميل الإنتاجي (Khwarizmi Flutter Client)

تطبيق متعدد المنصات (Windows Desktop, Android Mobile, Web) مبني بإطار عمل **Flutter** لتقديم تجربة رياضية استدلالية فريدة باللغة العربية.

## المميزات الرئيسية
- **كيبورد رياضي تفاعلي (MathKeyboard):** 4 أقسام تخصصية (حساب وأرقام، جبر وقوى، تفاضل ودوال، رموز وهندسة) مع ميزة الإدراج الذكي وتوجيه المؤشر داخل الأقواس.
- **معاينة حية دقيقة (KaTeX Preview):** تصيير فوري للمعادلات مع إغلاق تلقائي للأقواس ومنع الأخطاء النحوية.
- **تفاعل كامل مع كيبورد ويندوز:** دعم اختصارات `Enter` للحل، و `Escape` للمسح، و `F2` أو `Ctrl+K` للتحكم في الكيبورد.
- **فصل بصري بين النتيجة والشرح:** بطاقة زمردية بارزة للنتيجة الدقيقة، تليها بطاقات استدلالية تشرح كل خطوة باللغة العربية مع إمكانية نسخ أي خطوة بنقرة واحدة.

## التشغيل والتطوير
```bash
# تثبيت الحزم
flutter pub get

# تشغيل الاختبارات
flutter test

# تشغيل التطبيق على ويندوز أو الهاتف
flutter run
```
